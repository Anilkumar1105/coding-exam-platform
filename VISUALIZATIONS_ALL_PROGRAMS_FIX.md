# Code Visualizations — broader automatic traces

This update adds title/input-aware traces for common arithmetic, conditions, loops, digit processing, strings, lists, sorting, and pair-sum problems. It also stops generic two-step placeholder `visualizationSteps` from overriding automatic traces. The existing Excel `exampleInput` and `expectedOutput` values are displayed and used where supported.

For best results include title, description, code, exampleInput, expectedOutput. Leave visualizationSteps blank for automatic traces; supply meaningful JSON steps only when you want admin-defined steps.

This is a heuristic educational visualizer, not a full Python interpreter. Validate custom/unusual programs with their sample input and use custom steps where needed.
